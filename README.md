# Value at Risk (VaR) Analysis – Indian Banking Stocks

## 📌 Project Overview
This project implements Value at Risk (VaR) models to estimate market risk for a portfolio of major Indian banking stocks and the NIFTY 50 index using Python.

Three commonly used VaR methodologies are applied and compared:
- Parametric (Variance–Covariance) Approach
- Historical Simulation
- Monte Carlo Simulation

## 📊 Assets Covered
- Axis Bank  
- HDFC Bank  
- ICICI Bank  
- Kotak Mahindra Bank  
- NIFTY 50 Index  

## ⚙️ Methodology
- Daily log returns calculated from historical price data (15 years)
- Equal-weighted portfolio
- 5-day holding period
- VaR estimated at 90%, 95%, and 99% confidence levels

## 📈 Key Highlights
- Visual comparison of VaR across different methodologies
- Analysis of tail risk behavior
- Explicit assumptions stated for each approach
